# SaveNote – React + TypeScript

A simple and responsive note-taking web application built with React and TypeScript.

🌐 **Live Demo:** [https://savenote-blue.vercel.app/](https://savenote-blue.vercel.app/)

💻 **GitHub Repository:** [react-todo-typescript](https://github.com/ramgurav04/react-todo-typescript)

## About the Project

SaveNote is a web application designed to provide a simple interface for managing notes. This project is part of my learning journey with React and TypeScript, where I practice component-based development, type safety, and building interactive user interfaces.

## Features

- Simple and user-friendly interface
- Responsive design
- Built with reusable React components
- Type-safe development using TypeScript
- Live deployment on Vercel

## Tech Stack

- **React** – Building user interfaces
- **TypeScript** – Type safety and maintainable code
- **Vite** – Development server and build tool
- **Tailwind CSS** – Utility-first styling
- **Vercel** – Deployment

## Getting Started

Follow these steps to run the project locally.

### Prerequisites

- Node.js
- npm
- Git

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/ramgurav04/react-todo-typescript.git
   ```

2. Navigate to the project directory:

   ```bash
   cd react-todo-typescript
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal.
